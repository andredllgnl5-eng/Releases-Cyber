# Cyber

Protótipo Android de frontend de emulação com núcleo GBA incorporado, cartuchos NFC e atualizações por GitHub Releases.

As versões publicadas incluem o APK e o código fonte correspondente. O núcleo gpSP e a interface derivada de JustGBA usam GPLv2. ROMs comerciais não são incluídas.

Instale o APK mais recente pela página de Releases. Novas versões são verificadas pelo aplicativo ao abrir; o Android solicita confirmação antes da instalação.
